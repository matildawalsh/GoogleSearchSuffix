# GoogleSearchSuffix
Automatically adds -ai to every Google search.

1. Download the ZIP for this project, and unzip it. 
2. Go to the Chrome extensions page (chrome://extensions) and enable Developer Mode.
3. Turn on the toggle at the top right of the window and click "Load unpacked".
4. Select the unzipped foler.
5. Search Google for "cat" and check to make sure the search query has been changed to "cat -ai".
